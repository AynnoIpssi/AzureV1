# Problèmes trouvés en construisant Azure Docs en rsH/rsC

Relevés le 2026-09-22 en écrivant `ui/app.rsh` + `ui/app.rsc` (toute l'interface de l'app).
Captures hors fenêtre : `cargo test -p azure-docs --test screens`, puis `target/tmp/azure-docs-<page>.ppm`.

Le 2026-09-23, l'interface a été refaite comme un site de documentation (barre du haut, menu latéral, article centré, pages précédente/suivante, 15 pages) avec le modèle « web » de rsC (px, flux normal, hauteur selon le contenu). Voir #28 à #32.
